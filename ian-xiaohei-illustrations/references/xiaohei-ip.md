# 刺猬 IP

## 角色定义

刺猬是 Ian 中文正文配图的新固定视觉 IP，替代原来的小黑角色。

默认每张图都要出现刺猬。刺猬不是普通萌宠贴纸，也不是站在旁边的装饰物，而是温柔、认真、带一点笨拙手作感的内容工作者：它会背着小包、抱着乐器或工具，亲自参与画面里的核心动作。

## 参考图提炼

这只 IP 是一只穿衣服的拟人刺猬，整体气质是温暖、柔软、手绘、治愈、安静、有一点民谣旅行感。

关键识别点：

- 圆润矮胖的身体比例，头大、身体短、四肢短。
- 米白色脸部和肚皮，棕色刺毛从头顶、两侧和背部向外炸开。
- 刺毛不是尖锐武器，而是柔软蓬松的叶片状 / 火焰状毛束。
- 黑豆眼，黑色小圆鼻，短短的微笑嘴。
- 两侧有圆耳朵，耳内有浅粉或浅米色细节。
- 脸颊有柔和橘粉色腮红，是重要记忆点。
- 穿宽松米白毛衣，袖口和下摆有轻微针织纹理。
- 围橘棕色长围巾，围巾有褶皱、流苏和手绘线条。
- 穿橄榄绿色灯笼裤或宽松短裤。
- 背橄榄绿色斜挎小包，小包有圆扣和细肩带。
- 可以携带小吉他、尤克里里、铅笔、刷子、纸卷、工具箱等轻巧道具。
- 可画正面、侧面和背面，但都要保留刺毛轮廓、围巾、小包等高识别元素。

## 外形关键词

- anthropomorphic hedgehog character
- warm hand-drawn children-book illustration style
- round chubby body, short limbs, oversized head
- cream face and belly
- brown soft spiky hedgehog quills, fluffy leaf-like spikes
- tiny black bead eyes, small black round nose, subtle smile
- peach blush cheeks
- round ears with soft inner-ear details
- oversized cream knit sweater
- burnt-orange scarf with fringes
- olive green loose pants
- olive green crossbody satchel with button
- small acoustic ukulele or handmade tool prop
- soft pencil outline, warm watercolor wash, muted earthy palette

## 性格

- 温柔、安静、认真。
- 有手作感，像会慢慢整理素材、记录想法、修补系统的小伙伴。
- 有一点笨拙，但不蠢；像慢工出细活的内容工匠。
- 不夸张卖萌，不做表情包。
- 更偏治愈、民谣、旅行、手帐、童书插画气质，而不是潮玩或商业吉祥物。

## 常见职责

让刺猬承担核心动作：

- 抱着小吉他，把观点“弹”成一条线索。
- 从斜挎包里拿出纸条、标签、证据或小工具。
- 背着小包搬运素材、灵感和读者问题。
- 用围巾把分散的信息轻轻系在一起。
- 用小铅笔给内容打标、分组、排顺序。
- 把混乱纸团放进低科技机器里慢慢整理。
- 坐在旧木箱、邮筒、抽屉或小工位前做记录。
- 把输出交给读者、门口、桥、信箱或路径终点。
- 用小刷子、针线、夹子、印章等手作工具修补流程断点。
- 在画面中保持“认真做事”的状态，而不是摆拍。

## 画风关键词

- 温暖童书感，但不是低幼儿童卡通。
- 柔软手绘线稿，线条略微抖动，有铅笔 / 针管笔质感。
- 淡水彩或彩铅铺色，颜色轻、薄、透气。
- 暖米白背景，可以保留大量空白；不要脏旧纸纹。
- 棕色、米白、橘棕、橄榄绿为主色，少量红 / 橙 / 蓝批注仍要克制。
- 角色体积圆润，轮廓柔和，但刺毛要有清晰剪影。
- 画面像一本安静的手帐或童书角色设定稿，清爽、有呼吸感。

## 禁止

- 不要再画黑色实心小怪物、白点眼、细腿的小黑形象。
- 不要把刺猬画成真实动物、写实毛发或 3D 玩偶。
- 不要把刺画得尖锐、危险、像怪兽或攻击性武器。
- 不要去掉围巾、小包、米白毛衣、橄榄绿裤子等核心识别元素。
- 不要画成过度商业的 logo mascot、潮玩公仔或贴纸包。
- 不要画成迪士尼式大眼、高光眼、夸张表情。
- 不要画成幼儿园卡通、Q 版过头、糖果色过饱和。
- 不要给角色复杂服装、盔甲、科技装备或现代 UI 屏幕感。
- 不要让角色只是站在角落里看；它必须参与核心动作。
- 不要让道具喧宾夺主；吉他、小包、围巾和工具都要服务画面隐喻。

## 判断标准

如果去掉刺猬，图的核心隐喻还能完全成立，说明刺猬太装饰了；要重写提示词，让刺猬成为动作主体。

如果第一眼认不出“棕色刺毛 + 米白脸肚 + 橘棕围巾 + 米白毛衣 + 橄榄绿小包/裤子”的组合，说明 IP 识别度不够。
